# 🌆 Urban Spatio-Temporal Demand Forecasting Agent

A Deep Learning & Geospatial pipeline designed to forecast real-time urban traffic congestion and mobility demand across micro-zones using spatial LSTM networks.

## 📌 Features
- **Spatio-Temporal Modeling:** Integrates sequential time-series indicators with spatial grid coordinates.
- **Interactive Dashboard:** Built with Streamlit for dynamic zone selection and multi-hour demand projection.
- **PyTorch Architecture:** Customizable LSTM core ready for expansion to Graph Neural Networks (GNNs).

## 🛠️ Installation & Setup
```bash
git clone [https://github.com/mitchellechristophany/urban-spatiotemporal-forecasting.git](https://github.com/mitchellechristophany/urban-spatiotemporal-forecasting.git)
